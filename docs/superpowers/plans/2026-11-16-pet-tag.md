# Pet Tag Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A static page, opened from an NFC tag, that shows a pet's identification and vaccination record read from a Google Sheet that the tutor edits through a Google Form.

**Architecture:** `lib.js` holds pure functions for CSV parsing, dates, vaccine status and lookups, and is tested in Node with `assert`. `index.html` fetches the two published CSVs and renders the page with plain DOM, using `lib.js` as an ES module. It is hosted on GitHub Pages. No build step and no dependencies.

**Tech Stack:** HTML/CSS/vanilla JS (ES modules), Node ≥ 20 for `check.js`, Google Forms/Sheets/Drive (Gmail pessoal), GitHub Pages, NFC Tools app.

**Spec:** `docs/superpowers/specs/2026-11-16-pet-tag-design.md`

## Global Constraints

- No dependencies, no build, no server. Files: `index.html`, `lib.js`, `check.js`, `package.json` (only `{"type":"module"}`), `fotos/`, `exemplo/`.
- Tag URL: `https://<usuario>.github.io/pet-tag/?pet=<id>`. Do not rename the user or the repo.
- Alert window: **30 days**. Overdue = next dose before today. Due soon = from today up to and including today + 30.
- Dates in the CSV are `dd/mm/aaaa` (sheet locale pt-BR).
- `Pets` columns: `id, nome, foto, whatsapp, telefone, mensagem, microchip, alergias, remedios, perdido`.
- `Vacinas` columns (Form question titles, verbatim): `Carimbo de data/hora, Pet, Vacina, Data de aplicação, Próxima dose, Lote, Clínica / Veterinário, Comprovante`.
- Vaccine grouping by normalized name: `trim().toLowerCase()`.
- The 📷 link points to Drive and only opens for the logged-in tutor. This is intentional.
- The contact fallback is hardcoded in `index.html` and always shown, even when the CSV fails.
- UI copy is in Portuguese.

## Review Focus

1. Google CSVs come with `\r\n` and can end in a blank line. Rows must not shift, and no ghost row may appear (test in Task 1).
2. A Forms upload with more than one file puts `"url1, url2"` in the `Comprovante` cell. Use the first URL (Task 1).
3. In a pt-BR sheet, the `perdido` checkbox can come out as `VERDADEIRO`. Accept `true/verdadeiro/sim/1` in any case (Task 1).
4. The tutor may type the WhatsApp number as `+55 (11) 99999-9999`. `wa.me` needs digits only (Task 1).
5. The tag URL may arrive as `?pet=Thor`, with a trailing space or with no `pet` at all. The lookup must be case-insensitive and trimmed. If nothing matches, show "pet não encontrado" plus the fallback buttons (Task 1 for the lookup, Task 2 for the screen).

### Task 1: `lib.js`, pure functions with tests

**Files:**
- Create: `package.json`, `lib.js`, `check.js`, `.gitignore` (empty is fine)

**Interfaces:**
- Produces (all `export function` in `lib.js`):
  - `parseCSV(text: string) -> string[][]` parses RFC 4180: quotes, `""` escapes, commas and newlines inside quotes, `\r\n`. Drops fully empty rows.
  - `toObjects(rows: string[][]) -> object[]` uses the first row as keys, trimmed.
  - `parseDateBR(s: string) -> Date | null` reads `dd/mm/aaaa` (an optional time part after a space is ignored) and returns local midnight. Returns `null` for empty or invalid input.
  - `vaccineStatus(next: Date | null, today: Date) -> 'none' | 'ok' | 'soon' | 'overdue'`
  - `latestByVaccine(records: object[]) -> object[]` keeps the record with the latest `Data de aplicação` per normalized `Vacina`.
  - `findPet(pets: object[], id: string | null) -> object | null`
  - `isTrue(v: string) -> boolean`
  - `digits(s: string) -> string`
  - `firstUrl(s: string) -> string | null` splits on `,` or whitespace and returns the first item that starts with `http`.

- [ ] **Step 2: Write `check.js` with failing assertions**

```js
import assert from 'node:assert/strict';
import * as L from './lib.js';

// parseCSV
assert.deepEqual(L.parseCSV('a,b\r\n1,2\r\n'), [['a','b'],['1','2']]);
assert.deepEqual(L.parseCSV('a,b\n"x, y","l1\nl2"\n\n'), [['a','b'],['x, y','l1\nl2']]);
assert.deepEqual(L.parseCSV('a\n"diz ""oi"""'), [['a'],['diz "oi"']]);
assert.deepEqual(L.toObjects([[' id ','nome'],['thor','Thor']]), [{id:'thor', nome:'Thor'}]);

// datas e status (today = 16/11/2026)
const today = new Date(2026, 10, 16);
assert.equal(L.parseDateBR('03/12/2026').getTime(), new Date(2026, 11, 3).getTime());
assert.equal(L.parseDateBR('16/11/2026 10:00:00').getTime(), today.getTime());
assert.equal(L.parseDateBR(''), null);
assert.equal(L.parseDateBR('lixo'), null);
assert.equal(L.vaccineStatus(null, today), 'none');
assert.equal(L.vaccineStatus(new Date(2026, 10, 15), today), 'overdue');
assert.equal(L.vaccineStatus(today, today), 'soon');
assert.equal(L.vaccineStatus(new Date(2026, 11, 16), today), 'soon');   // +30
assert.equal(L.vaccineStatus(new Date(2026, 11, 17), today), 'ok');     // +31

// latestByVaccine
const recs = [
  {Vacina:'V10', 'Data de aplicação':'01/01/2025'},
  {Vacina:' v10 ', 'Data de aplicação':'01/01/2026'},
  {Vacina:'Raiva', 'Data de aplicação':'10/01/2026'},
];
const latest = L.latestByVaccine(recs);
assert.equal(latest.length, 2);
assert.equal(latest.find(r => r.Vacina.trim().toLowerCase()==='v10')['Data de aplicação'], '01/01/2026');

// Review Focus helpers
assert.equal(L.findPet([{id:'thor'}], ' Thor ').id, 'thor');
assert.equal(L.findPet([{id:'thor'}], null), null);
assert.equal(L.findPet([{id:'thor'}], 'rex'), null);
for (const v of ['TRUE','verdadeiro','Sim','1']) assert.equal(L.isTrue(v), true);
for (const v of ['FALSE','FALSO','', undefined]) assert.equal(L.isTrue(v), false);
assert.equal(L.digits('+55 (11) 99999-9999'), '5511999999999');
assert.equal(L.firstUrl('https://drive.google.com/a, https://drive.google.com/b'), 'https://drive.google.com/a');
assert.equal(L.firstUrl(''), null);

console.log('ok');
```

### Task 2: `index.html`, page rendering

**Files:**
- Create: `index.html`, `exemplo/pets.csv`, `exemplo/vacinas.csv`, `fotos/exemplo.jpg` (any small image)

**Interfaces:**

  ```js
  const CSV_PETS = 'COLE_AQUI';
  const CSV_VACINAS = 'COLE_AQUI';

  ```

- [ ] **Step 2: Implement `index.html`**

The page renders in the order from the spec:
1. Red banner "ESTOU PERDIDO" when `isTrue(pet.perdido)`.
2. Photo, name and message.
3. Alerts. For each record from `latestByVaccine` filtered to the pet: `overdue` shows in red as "⚠ {Vacina} atrasada desde {data}", and `soon` shows in yellow as "{Vacina} vence em {n} dias".
4. Buttons:
   - WhatsApp: `https://wa.me/${digits(pet.whatsapp || CONTATO.whatsapp)}`.
   - Ligar: `tel:`.
   - Enviar localização: `getCurrentPosition` with `{timeout: 10000}`. It opens wa.me with `text=Achei o {nome}! Estou aqui: https://maps.google.com/?q={lat},{lng}`. On error it sends only `Achei o {nome}!`.
5. Saúde: microchip, alergias and remédios. Hide empty fields.
6. Histórico: every record for the pet, newest first. Columns: vacina, aplicação, próxima dose, lote. Add a 📷 `<a target="_blank">` linking to `firstUrl(Comprovante)` when the record has one.

Error cases:
- When `findPet` returns `null` or a `fetch` fails, show "Pet não encontrado" or "Não consegui carregar os dados agora", plus the WhatsApp and Ligar buttons using `CONTATO`.
- Fetch both CSVs with `{cache: 'no-store'}`.
- Use mobile-first CSS with buttons at least 44px tall. Use `textContent`, never `innerHTML`, for data from the sheet.
